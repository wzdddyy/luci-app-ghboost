下载证书 (ghboost-ca.crt) 装到系统根证书库后，浏览器 / Git / GitHub Desktop 会自动信任
Windows macOS Linux iOS Android Firefox

以管理员身份打开 PowerShell，安装到「本地计算机 → 受信任的根证书颁发机构」。只装到当前用户目录时，Git、GitHub Desktop 等工具识别不到。

certutil -addstore -f Root C:\Users\你\Downloads\ghboost-ca.crt
注意：Chrome / Edge 114+ 使用内置根证书库，若仍提示不受信任，需在浏览器设置中单独导入该证书。

在终端执行，将证书加入系统钥匙串并设为始终信任。

sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain ~/Downloads/ghboost-ca.crt

系统证书库只对 curl、git 等命令行工具生效，浏览器不读取它，需单独导入（见下方命令）。

sudo cp ~/Downloads/ghboost-ca.crt /usr/local/share/ca-certificates/ghboost-ca.crt && sudo update-ca-certificates

Edge / Chrome 使用独立的 NSS 证书库，先安装 certutil 再导入，导入后完全退出浏览器再打开。

sudo apt install libnss3-tools && certutil -d sql:$HOME/.pki/nssdb -A -t "C,," -n "ghboost CA" -i ~/Downloads/ghboost-ca.crt
注意：若提示数据库不存在，先执行 mkdir -p ~/.pki/nssdb && certutil -d sql:$HOME/.pki/nssdb -N（提示设密码时直接回车留空），再执行上面的导入命令。

下载证书后依次进入：设置 → 已下载描述文件 → 安装；再到 设置 → 通用 → 关于本机 → 证书信任设置，打开 ghboost CA 的完全信任开关。

下载证书后进入：设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书，选择刚下载的文件。

Firefox 使用独立证书库，不读取系统证书：选项 → 隐私与安全 → 证书 → 查看证书 → 证书颁发机构 → 导入，勾选信任该 CA。

也可在终端执行（需先 sudo apt install libnss3-tools；导入前必须彻底关闭 Firefox，否则数据库被锁会报错）：

pkill firefox; sleep 2; certutil -d sql:$HOME/.mozilla/firefox/*.default-release -A -t "C,," -n "ghboost CA" -i ~/Downloads/ghboost-ca.crt
注意：若 Firefox 是 snap / flatpak 安装的，或导入仍报错，请改用上面的界面导入方式，效果相同。
